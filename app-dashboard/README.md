# דשבורד מנהלים · AILON

מסך אחד לכל האפליקציות: תיאור של שתי שורות, כפתור כניסה, קישור להעתקה, ומספרים וגרפים על מצב המערכת.

## הקבצים
- `index.html` — המסך עצמו (סטטי, קורא את `apps.json`).
- `apps.json` — מקור האמת לרשימת האפליקציות: שם, תיאור, קטגוריה, סטטוס, קישור, תאריך עדכון אחרון וגודל.
- `assets/ailon-logo.png` — הלוגו הרשמי של AILON.

## הוספת אפליקציה חדשה
כל תיקייה חדשה עם `index.html` צריכה להופיע ב-`apps.json`. עדכון אוטומטי רץ פעם ביום ומוסיף כל אפליקציה שחסרה (עם שם מה-`<title>` ותיאור מה-`meta description`), ואפשר ואף רצוי לחדד ידנית את שדות `name`, `desc`, `desc2`, `cat` ו-`status`.

שדות:
- `cat` — אחת מהקטגוריות ב-`categories`: עסקים, פוראטוס, מנטורינג, מסכים ולוחות, תוכן ויהדות, ילדים ולמידה, אישי ומשפחה, פורטלים.
- `status` — `live` (פעיל), `beta` (בבנייה), `demo`, `archived` (ארכיון).
- `url` — ברירת המחדל היא `https://lior-ailon.github.io/ailon-task-apps/<slug>/`; אפליקציה שמתארחת בריפו אחר מקבלת כתובת מלאה משלה.
- `children` — תתי-מסכים בתוך אותה אפליקציה (למשל כלים בתוך Mentor-IT).

## כללים
- חוק היק: כפתור ראשי אחד לכל כרטיס (כניסה לאפליקציה), והעתקת הקישור משנית מתחתיו.
- אין מספרי שימוש מומצאים. "עודכן לפני X ימים" מגיע מתאריך הקומיט האחרון של התיקייה.
