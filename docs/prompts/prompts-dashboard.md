### 1. תכנון דשבורד KPI ראשי (KPI Dashboard Design)

**מתי להשתמש?** כשנדרש מסך ניהולי מרכזי המציג מדדים עסקיים, מגמות וגרפים עיקריים.

```markdown
אתה מומחה לעיצוב דשבורדים וויזואליזציה של נתונים (Data Visualization Expert).
עצב דשבורד KPI ראשי עבור [שם האפליקציה]:

### 1. היררכיה ויזואלית (Visual Hierarchy)
- **חלק עליון (Top Row):** 4 כרטיסיות KPI מרכזיות (Stats Cards):
  - ערך נוכחי (בפונט גדול ומודגש).
  - אחוז שינוי לעומת תקופה קודמת (עם חץ ירוק למעלה / אדום למטה).
  - אייקון ייעודי לכל מדד.
- **חלק מרכזי (Main Section):**
  - גרף מגמה ראשי (Area/Line Chart) המציג נתונים לאורך זמן (יומי/שבועי/חודשי).
  - גרף התפלגות משני (Bar/Donut Chart) המציג פילוח לפי קטגוריות.
- **חלק תחתון (Bottom Section):** טבלת פעילויות אחרונות (Recent Activity).

### 2. כללים לבחירת גרפים
- השתמש ב-Line/Area Chart לטרנדים לאורך זמן.
- השתמש ב-Bar Chart להשוואה בין 3-7 קטגוריות.
- הימנע מגרפי עוגה (Pie Charts) מסובכים — העדף Donut Chart עם מקסימום 4 פרוסות או Bar Chart.

### 3. התאמה ל-RTL
- סדר הכרטיסיות מימין לשמאל: המדד החשוב ביותר מימין.
- ציר ה-X וה-Y בגרפים מקבילים ומיושרים לכיוון עברית.

צור את מבנה ה-HTML/React וה-CSS עבור דשבורד זה עבור [שם האפליקציה].
```

### 2. דשבורד סטטוס ובריאות מערכת (Status & Health Dashboard)

**מתי להשתמש?** למעקב בזמן אמת אחר זמינות שירותים, תהליכי ברקע, שגיאות ותקינות המערכת.

```markdown
אתה ארכיטקט מערכות ומעצב UI. תכנן דשבורד סטטוס ובריאות (System Health & Operational Status) עבור [שם האפליקציה]:

### 1. רכיבי הסטטוס המרכזיים:
- **באנר סטטוס כללי (Overall Health Banner):**
  - ירוק: "כל המערכות פועלות כסדרן".
  - צהוב: "האטה או פגיעה חלקית בשירות".
  - אדום: "תקלה קריטית או השבתה".
- **רשת שירותים (Service Matrix):**
  - רשימת רכיבי המערכת (בסיס נתונים, API, שרת קבצים, חיבורי WhatsApp/SMS).
  - לכל שירות: שם, אינדיקטור צבעוני (Dot Badge), זמן תגובה (Latency ב-ms), ואחוז זמינות (Uptime %).
- **יומן אירועים ותקלות (Incidents & Logs):**
  - רשימת אירועים אחרונים לפי חותמת זמן (Timestamp), חומרה (Info, Warning, Error) ותיאור.

### 2. אינטראקציות:
- כפתור "רענן נתונים" בלחיצה ידנית + אינדיקטור לזמן הרענון האחרון ("עודכן לפני 12 שניות").
- אפשרות לסנן לוגים לפי רמת חומרה.

צור את הרכיב ב-React / HTML עם Tailwind CSS.
```

### 3. תצוגת טבלת נתונים מתקדמת (Data Table with Filters, Sort & Export)

**מתי להשתמש?** להצגת רשימות מורכבות (לקוחות, הזמנות, משימות, מוצרים) הדורשות ניהול, סינון וייצוא.

```markdown
אתה מעצב ומפתח פרונטאנד בכיר. צור רכיב טבלת נתונים מתקדמת (Advanced Data Table) עבור [שם הישות, למשל: הזמנות / לקוחות] ב-[שם האפליקציה]:

### 1. סרגל כללים עליון (Table Header & Toolbar):
- שדה חיפוש חופשי (Search Bar) בזמן אמת.
- פילטרים מהירים (Quick Filter Chips) לפי סטטוס.
- כפתור "ייצוא" (Export to CSV/Excel).
- כפתור "הוסף חדש" (Primary Action CTA).

### 2. גוף הטבלה (Table Body):
- עמודות מותאמות: מזהה, שם, תאריך, סטטוס (Badge צבעוני), סכום/פרטים, ופעולות (Actions menu).
- מיון (Sorting): לחיצה על כותרת עמודה ממיינת בסדר עולה/יורד (עם אריח חץ).
- פעולות שורה: כפתור עריכה, צפייה בפרטים, ומחיקה.
- תמיכה בבחירת שורות מרובות (Checkboxes) לפעולות באצווה (Bulk Actions).

### 3. חלק תחתון ופגינציה (Pagination Footer):
- הצגת כמות רשומות ("מציג 1-10 מתוך 142").
- דפדלור עמודים (הקודם / הבא / מספרי עמודים) מותאם ל-RTL.
- בחירת כמות רשומות לעמוד (10, 25, 50).

ספק קוד מלא כולל מצב ריק (Empty State) כשאף רשומה לא נמצאה.
```

### 4. סרגל סינון חכם וחיפוש דינמי (Dynamic Filter Bar)

**מתי להשתמש?** כאשר הדשבורד או הטבלה מכילים נתונים רבים ונדרשת יכולת סינון חזקה וגמישה.

```markdown
אתה מעצב UX ומפתח פרונטאנד. צור סרגל סינונים חכם (Dynamic Filter Bar) עבור [שם האפליקציה]:

### דרישות הרכיב:
1. **שדה חיפוש טקסטואלי:** חיפוש מהיר לפי מילות מפתח עם כפתור ניקוי (X).
2. **סינון לפי תאריכים:** דרופדאון בחירת טווח (היום, 7 ימים אחרונים, החודש, מותאם אישית).
3. **סינון לפי קטגוריה / סטטוס:** Multi-select dropdown עם צ'קבוקסים.
4. **תיוג פילטרים פעילים (Active Filter Chips):** הצגת תגיות מעל הטבלה של הסינונים הפעילים, עם אפשרות להסיר פילטר בודד ב-X או "נקה הכל".
5. **נגישות ו-RTL:** התאמה מלאה לעברית, יישור מימין לשמאל, וניווט מקלדת.

צור רכיב React / Tailwind גמיש שניתן לחיבור לכל טבלה או דשבורד.
```

### 5. דשבורד מותאם ל-Mobile ו-RTL (Responsive Dashboard)

**מתי להשתמש?** להבטחת חווית משתמש מושלמת בדשבורד גם במסכי סמארטפון וטאבלט.

```markdown
אתה מומחה Responsive Design ו-Mobile UX. קח את הדשבורד של [שם האפליקציה] והתאם אותו בצורה מושלמת למכשירים ניידים:

### חוקי ההתאמה לנייד:
1. **כרטיסיות KPI:** המרה מרשת של 4 עמודות לגלילה אופקית (Horizontal Scroll Swiper) או 2 עמודות במסך נייד.
2. **טבלאות נתונים:** המרת טבלה רחבה לכרטיסיות אנכיות (Card List View) במסכים מתחת ל-768px, כך שכל רשומה מוצגת ככרטיס נקי עם הפרטים הקריטיים.
3. **גרפים:** התאמת גובה הגרף והסתרת מקרא (Legend) עמוס, או העברתו מתחת לגרף.
4. **תפריט ניווט:** המרת ה-Sidebar לתפריט המבורגר (Bottom Navigation Bar / Drawer) הנגיש באגודל.

ספק את מחלקות ה-Tailwind והפתרון הטכני להתאמה זו.
```
