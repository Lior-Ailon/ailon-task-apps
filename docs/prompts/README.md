# ספריית הפרומפטים של AILON — מדריך ואינדקס

ספרייה זו מכילה פרומפטים מוכנים לשימוש (Ready-to-Copy) עבור ליאור וצוות הפיתוח של AILON, המיועדים לעבודה מול סוכני AI (כגון Claude, GPT, Base44 Agents) לבנייה, עיצוב, שיפור ומיתוג של אפליקציות ווב.

כל פרומפט בספרייה נכתב בגישה מעשית ("העתק-הדבק"), וכולל מציין מיקום (Placeholders) כגון `[שם האפליקציה]` או `[תיאור המשתמש]` אותם יש להחליף לפני השליחה לסוכן.

---

## 📁 מבנה הספרייה והקבצים

| שם הקובץ | תיאור קצר | מתי להשתמש? |
|---|---|---|
| **[prompts-app-spec.md](./prompts-app-spec.md)** | אפיון אפליקציה חדשה | בתחילת מיזם חדש — להגדרת בעיה, משתמשים, חוק היק, ישויות ומסכים. כולל דוגמה מעשית מלאה. |

## 💡 עקרונות עבודה עם הספרייה

1. **העתקה והחלפת משתנים:** העתק את בלוק הקוד המבוקש והחלף את כל הערכים בסוגריים מרובעים `[...]` בפרטי הפרויקט שלך.
2. **שרשור פרומפטים (Prompt Chaining):** מומלץ להתחיל ב-`prompts-app-spec.md` כדי ליצור אפיון חזק, לאחר מכן להגדיר עיצוב ב-`prompts-ui-design.md`, ולבסוף להחיל מיתוג דרך `prompts-branding.md`.
3. **עברית ו-RTL תמיד בראש:** כל הפרומפטים מונחים לייצר ממשק עברי מלא (Right-to-Left) שמתאים באופן טבעי למשתמש הישראלי.
4. **עקרון הפשטות (Hick's Law):** דגש על צמצום אפשרויות בחירה בכל מסך, כפתור פעולה ראשי אחד (Primary CTA) ומניעת עומס קוגניטיבי.
